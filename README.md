# PaperDesk public papers

This repository holds research paper packages that I explicitly choose to publish from my local PaperDesk library. Packages appear under `shares/<share-id>/`.

Each package contains the selected original PDF, its annotations, and its paper notes. Cross-paper ideas are included only when selected separately. My local library, backups, archived notes, and Caseboard boards are not automatically uploaded.

本仓库只保存我在 PaperDesk 中预览并确认公开的论文分享包。分享前请检查 PDF 的再发布权限，以及批注和笔记中的私人信息。
